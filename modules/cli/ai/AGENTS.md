# AGENTS.md

## 沟通

* 始终使用中文与用户沟通。
* 代码、命令、文件名等技术内容保持原文。

## 开发

* 修改代码前先阅读相关实现。
* 遵循项目现有代码风格和配置。
* 优先进行最小化修改，避免无关重构。

## Git

* 未经用户在当前会话中明确授权，不得执行 `git push`。
* 创建 commit 不代表获得 push 权限。
* 不得主动执行 `git push --force`、`git push --mirror`。
* 不得主动执行 `git push --tags`。
* 不得创建、修改或删除远程仓库配置。
* 当用户要求发布、同步代码、上传代码、推送代码或进行类似操作时，执行前仍需确认是否允许执行 `git push`。

## Commit Message

生成提交信息前必须查看当前暂存区变更：

```bash
git status
git diff --cached
```

* 提交信息仅基于已暂存的内容生成。
* 优先参考项目历史提交风格。
* 如果历史提交存在明确规范，则保持一致。
* 如果历史提交无明显风格或规范，则使用 Conventional Commits 规范。

## 代码风格

* 遵循项目中的 ESLint、Prettier、Biome 等配置。
* 不要因个人偏好修改代码格式。
